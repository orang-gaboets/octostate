# Security Policy

## Supported Versions

Only the latest released version of `octostate` receives security fixes.

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through public GitHub
issues.

Report vulnerabilities through GitHub private vulnerability reporting for this
repository. Include as much of the following information as possible:

- the affected `octostate` version or commit
- reproduction steps or a proof of concept
- expected impact
- relevant logs, configuration snippets, or command output with secrets removed
- any suggested fix or mitigation

The maintainer will triage the report, coordinate follow-up through GitHub
Security Advisories when appropriate, and publish fixes in a release once a
validated vulnerability is addressed.
